# Security policy

## Supported versions

Only the latest released minor version of `trysac-unsupported-claim-flagger` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub private vulnerability reporting:
https://github.com/Trysac/u208-unsupported-claim-flagger/security/advisories/new

You will get an acknowledgement within 7 days. Once a fix is released, the advisory is published
with credit to the reporter unless they prefer otherwise.
